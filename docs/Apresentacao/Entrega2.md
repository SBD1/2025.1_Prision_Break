# Entrega 02 - SQL

Nesta segunda entrega, buscamos avançar no desenvolvimento do projeto por meio da criação e implementação da estrutura do banco de dados, utilizando a linguagem SQL. Com base na modelagem realizada na primeira entrega, trabalhamos na definição dos comandos necessários para transformar o modelo lógico em um ambiente funcional e pronto para receber e manipular dados no contexto do jogo Prison Break.  

Durante esta etapa, a equipe elaborou os scripts SQL para a criação das tabelas, incluindo a definição das chaves primárias, chaves estrangeiras, índices e restrições que asseguram a integridade referencial e o correto relacionamento entre as informações. Além disso, desenvolvemos os comandos de inserção inicial dos dados (inserts) para popular as tabelas com informações base, permitindo a realização de testes e simulações no ambiente de banco de dados. Os artefatos construidos desta entrega são:

- **DDL (Data Definition Language)** – responsável pela criação da estrutura do banco de dados, incluindo as definições das tabelas, tipos de dados, chaves primárias, chaves estrangeiras e restrições necessárias para garantir a integridade e consistência das informações;

- **DML (Data Manipulation Language)** – conjunto de comandos utilizados para inserir, atualizar e excluir registros nas tabelas, permitindo a manipulação dos dados de forma alinhada às regras de negócio e ao funcionamento esperado do sistema;

- **DQL (Data Query Language)** – comandos empregados para realizar consultas ao banco de dados, possibilitando extrair informações relevantes, aplicar filtros, ordenações e agrupamentos, e validar a coerência dos dados armazenados;

- **Álgebra Relacional** – representação formal das consultas realizadas no banco de dados, expressando de maneira matemática as operações de seleção, projeção, junção, agrupamento e outras, fundamentais para a análise e validação dos dados do sistema.
